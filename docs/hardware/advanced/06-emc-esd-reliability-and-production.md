## EMC/ESD、可靠性与量产测试

硬件产品从“实验室样机 (Prototype)”走入“工业级大批量生产 (Mass Production)”，难度往往上升一个数量级。本章将系统梳理**电磁兼容 (EMC)**、**静电防护 (ESD)**、**器件降额 (Derating)** 以及 **产线自动化测试 (ATE/ICT)** 的落地工程方法。

---

## 1. 电磁兼容 (EMC) 与电磁干扰 (EMI) 控制

EMC (Electromagnetic Compatibility) 包含两大要求：
1. **EMI (Electromagnetic Interference)**：电路对外辐射和传导的干扰能量要低于国家/国际标准（如 CE, FCC Class B）。
2. **EMS (Electromagnetic Susceptibility)**：电路自身对外部静电、电快速瞬变脉冲群 (EFT)、雷击浪涌具有足够的抗扰度。

### 1.1 EMI 产生的三要素

```text
        [ 干扰源 ] ------------[ 耦合路径 ]------------> [ 敏感设备 ]
   (DCDC/开关MOS/晶振)      (传导/空间辐射/共模)         (ADC/MCU/传感器)
```

### 1.2 EMI 整改黄金三板斧

1. **源头抑制**：
   - 开关 MOS 管栅极加小阻值电阻（如 $10\,\Omega \sim 22\,\Omega$）减缓开关边沿 $dv/dt$，降低高频振荡。
   - 在 DCDC 开关节点 SW 加 **RC 阻尼钳位回路 (Snubber Circuit: $R \sim 4.7\,\Omega + C \sim 1\text{nF}$)**。
2. **切断路径**：
   - 在差分高速信号（USB, CAN）接口处串联**共模电感 (Common Mode Choke)**。
   - 使用磁珠 (Ferrite Bead) 隔离数字电源与模拟电源 ($AVDD$)。
3. **敏感屏蔽**：
   - 屏蔽罩 (Shielding Can) 将射频或敏感模拟前端整体包覆并多点接地。

## 2. ESD 静电防护电路设计

静电放电 (ESD) 具有电压极高 (几千伏至几万伏)、上升沿极陡 (< 1ns)、能量瞬态大的特点，极易直接击穿芯片敏感端口。

```text
                    经典外设接口 ESD 保护电路
                    
   外部接插件                                    后级 IC 引脚
   (如 USB D+) ----+------------[ 10Ω 电阻 ]--------> (MCU GPIO)
                   |
                [ TVS 管 ]
                   |
                  GND
```

### 2.1 TVS 管选型四大黄金参数

- **反向截止电压 $V_{RWM}$**：必须略大于线路正常工作的最大电压（如 3.3V 信号线选 $V_{RWM} = 5\text{V}$ 的 TVS）。
- **击穿电压 $V_{BR}$**：TVS 开始动作导通的电压。
- **钳位电压 $V_C$**：在大冲击电流下 TVS 端的最大残压，**$V_C$ 必须小于后级被保护芯片的最高极限耐压**！
- **结电容 $C_j$**：对于高速信号线（如 USB 3.0, HDMI），TVS 结电容必须极小 ($< 0.5\text{pF}$)，否则会严重拉低信号边沿导致眼图闭合！

## 3. 可靠性设计与器件降额规范 (Derating)

降额设计是将器件施加的应力（电压、电流、功率、温度）降到额定值以下，以大幅提高产品平均无故障时间 (MTBF)。

### 3.1 工业级常见器件降额矩阵

| 器件类型 | 应力参数 | 降额等级 (常用 80% 降额规则) | 示例/建议 |
| :--- | :--- | :--- | :--- |
| **贴片电容 (MLCC)** | 工作电压 $V_{work}$ | **50% ~ 70%** | 5V 电源线上电容耐压至少选 $10\text{V}$ 或 $16\text{V}$（规避 DC 偏置衰减） |
| **功率 MOSFET** | 漏源耐压 $V_{DS}$ | **75% ~ 80%** | 24V 输入 Buck 拓扑中，MOSFET $V_{DS}$ 耐压选择 $\ge 40\text{V} \sim 60\text{V}$ |
| **电阻器** | 额定功率 $P_{rating}$ | **50%** | 实际功耗 $0.1\text{W}$ 的电阻，选用额定功率 $\ge 0.2\text{W}$ 的封装（如 0805） |
| **铝电解电容** | 纹波电流 / 温度 | **温度降低 $10^\circ\text{C}$，寿命翻倍** | 尽量选用 $105^\circ\text{C}$ 长寿命高频低阻电容 |

## 4. 可制造性测试 (DFA/ATE) 与量产流程

在产线批量装配阶段，为确保每一块出厂 PCB 都无焊接缺陷（短路、虚焊、错件），需要完善的自动化测试体系：

```text
                      量产 ATE 自动化测试流程
                      
  板卡上线 ---> ICT 针床测试 (线路短路/开路/电阻电容测定) ---> 烧录固件/校准 ---> FCT 功能测试 ---> 高低温老化 (Burn-In)
```

- **测试点 (Test Point) 布置要求**：
  - 测试点直径建议 $\ge 1\text{mm}$ (40mil)，测试点间距 $\ge 2.54\text{mm}$，便于自动化针床探针接触。
  - 所有关键电源轨 ($3.3\text{V}, 5\text{V}, GND$)、SW 调试引脚、串口 TX/RX 和模拟采样节点均必须导出测试点。
