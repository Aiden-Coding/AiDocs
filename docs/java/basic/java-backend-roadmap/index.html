Java 后端知识体系补充路线

当前 Java 专题已深入覆盖集合、并发、JVM、Spring、微服务、持久层与 Netty。本文补充从日常开发到生产运行的学习路径，优先填补工程基础与通用后端能力。

第一阶段：Java 日常开发基础​

目标：熟练编写可读、可维护的 Java 业务代码。

  • 类型系统、运算符、流程控制、类与接口、继承与组合。
  • 字符串、日期时间、正则、Optional 和集合的常用 API 与选择。
  • 异常设计、资源管理、不可变对象与基本代码组织。
  • 先读Java 日常开发语言基础，再衔接现有的集合源码专题和核心机制专题。

第二阶段：构建、测试与工程协作​

目标：能构建、验证并协作维护一个标准 Java 项目。

  • Maven/Gradle 项目结构、依赖管理、生命周期、多模块构建与制品发布。
  • JUnit 单元测试、Mockito 测试替身、集成测试、测试数据与边界场景。
  • 代码格式与静态检查、持续集成流水线、版本和发布流程。
  • 按Java 构建与测试实践完成构建与测试基础。

第三阶段：数据库与数据访问基础​

目标：理解应用访问关系型数据库时的关键行为和性能边界。

  • SQL 查询、表设计、索引、执行计划与常见慢查询。
  • 事务隔离级别、锁、并发更新和数据一致性基础。
  • JDBC 连接、参数绑定、事务控制及其与连接池的关系。
  • 先读Java 后端数据库基础，再衔接现有的 MyBatis、连接池与 ShardingSphere 专题。

第四阶段：服务端通用能力​

目标：掌握构建可靠 Web 服务所需的通用约定。

  • REST API 设计、参数校验、统一错误响应、分页与幂等性。
  • 配置管理、结构化日志、缓存和消息队列的基础使用与常见故障。
  • 身份认证、权限控制、输入处理和常见 Web 安全问题。
  • 与现有的 Spring Security、Spring Cache、微服务治理和可观测性专题配合学习。

第五阶段：部署与生产运行​

目标：能把 Java 服务部署运行，并完成基础诊断。

  • Linux 进程、文件、端口、日志和网络排障常用操作。
  • Docker 镜像、容器运行、环境配置、健康检查与日志采集。
  • 服务启动与关闭、运行参数、基础监控和发布回滚流程。
  • 与现有的 JVM 调优和线上故障复盘专题配合学习。

推荐顺序​

先完成第一、二阶段，建立语言与工程基础；再学习数据库基础；随后按项目需要补充服务端能力和部署运行。现有并发、JVM、Spring、微服务和 Netty 专题可穿插学习，作为原理与专项进阶材料。

完成标准​

  • 能独立创建并构建一个多模块 Java 服务项目。
  • 能为核心业务逻辑编写单元测试和集成测试。
  • 能根据执行计划和索引定位常见 SQL 性能问题。
  • 能设计带校验、错误处理和日志的服务接口。
  • 能将服务容器化运行，并完成基础日志、进程和网络排障。
